# AI-Arduino-LED-QA

## Project Description

This project demonstrates LED blinking using an Arduino Uno.
The project uses GitHub for code management, QA issue tracking,
collaboration and project planning.

## Hardware Used

- Arduino Uno
- Built-in LED / LED
- USB cable

## Software Used

- Arduino IDE
- GitHub
- AI Assistant

## Working

The Arduino turns the LED ON for one second and OFF for one second
continuously.

## AI Usage

AI was used for:
- Initial code generation
- Code review
- QA issue identification
- Root-cause analysis
- Test case preparation
- Documentation assistance

## QA Process

Potential issues were identified using AI-assisted code review.
Issues were logged in GitHub Issues and resolved through code
modification and testing.

## Expected Output

The LED should blink continuously with a one-second ON and
one-second OFF interval.
